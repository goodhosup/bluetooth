# 무선 전파와 링크 버짓

!!! spec "규격 · 버전"
    Core v6.0 Vol 6 Part A (LE Radio: 수신 감도, 출력) · Vol 2 Part A (BR/EDR Radio) · Vol 4 Part E (HCI: `HCI_Read_RSSI`, 광고 보고의 RSSI 필드)
    4.0 LE 1M → 5.0 LE 2M·Coded PHY(S=2, S=8)로 감도·거리 선택지 확대

!!! basic "한눈에 보기"
    전파는 멀어질수록, 장애물이 많을수록 약해집니다. **링크 버짓(link budget)**은 "보낸 힘에서 길에서 잃는 만큼을 빼도 받는 쪽이 알아들을 수 있나"를 따지는 dB 단위 가계부입니다.

    \[ \text{수신 전력} = \text{송신 출력} + \text{안테나 이득} - \text{경로 손실} - \text{기타 손실} \]

    수신 전력이 **수신 감도**보다 크면 통신이 됩니다. Coded PHY 같은 기술은 감도를 낮춰(더 약한 신호도 알아듣게) 거리를 늘립니다. 2.4 GHz에서는 벽, 가구, 그리고 무엇보다 **사람 몸**이 큰 손실을 만듭니다.

## 경로 손실 { .l2 }

장애물 없는 자유 공간에서 거리 \(d\), 주파수 \(f\)일 때 손실은

\[
L_{FS}(d) = 20\log_{10}\!\left(\frac{4\pi d f}{c}\right)\ \text{dB}
\]

입니다. 2.44 GHz에서 1 m 손실은 약 **40.2 dB**이고, 이후 거리가 2배가 될 때마다 6 dB씩 늘어납니다. 실내에서는 벽과 사람 때문에 더 빨리 감쇠하므로 **로그 거리 모델**을 씁니다.

\[
L(d) = L(1\,\text{m}) + 10\,n\log_{10}(d/1\,\text{m})
\]

| 환경 | 경로 손실 지수 \(n\) (대략) | 거리 2배당 추가 손실 |
|---|---|---|
| 자유 공간·가시선 | 2 | 6 dB |
| 사무실·주택 (가시선 일부) | 2.5–3 | 7.5–9 dB |
| 벽·층을 여러 번 통과 | 3–4 이상 | 9–12 dB 이상 |

| 장애물 (2.4 GHz, 대략) | 손실 |
|---|---|
| 석고 보드 벽 | 수 dB |
| 콘크리트·벽돌 벽 | 10 dB 이상 |
| 금속 (문, 엘리베이터, 차체) | 사실상 차단, 틈으로 새는 전파에 의존 |
| 사람 몸 통과 | 10–30 dB 수준까지 보고됨 (자세·거리·안테나에 따라 크게 다름) |

장애물 손실은 재질·두께·입사각에 따라 크게 달라지므로 위 값은 감을 잡는 용도입니다.

## 다중 경로와 페이딩 { .l2 }

실내에서는 직접 경로 외에 벽·바닥·천장에 반사된 여러 경로가 함께 도착합니다. 이들이 서로 보강·상쇄하면서 수신 세기가 몇 cm 차이로 크게 바뀌는 현상이 **다중 경로 페이딩**입니다. 2.4 GHz 파장은 약 12 cm이므로, 기기를 반 파장(6 cm)만 움직여도 수신 세기가 10–20 dB 오르내릴 수 있습니다.

| 현상 | 원인 | Bluetooth의 대응 |
|---|---|---|
| 주파수 선택적 페이딩 | 경로 지연 차이로 특정 주파수만 상쇄 | **주파수 도약**: 다음 패킷은 다른 채널에서 → 자연스러운 주파수 다이버시티 |
| 시간 변동 페이딩 | 사람·기기 이동 | 재전송(ACK/NACK), 연결 감독 타임아웃 여유 |
| 인체 차폐 | 주머니 속 휴대폰, 머리 반대편 이어폰 | 링크 버짓 마진, 안테나 배치, 이어폰 간 중계 구조 |

## 링크 버짓 예제: LE 1M vs Coded S=8 { .l2 }

같은 기기에서 PHY만 바꾸면 도달 거리가 얼마나 달라지는지 계산해 봅시다. 가정은 다음과 같습니다.

- 송신 출력 0 dBm, 양쪽 안테나 이득 0 dBi
- 수신 감도(가정한 칩 값): 1M −95 dBm, Coded S=8 −103 dBm (실제 칩은 데이터시트 값 사용)
- 페이딩·인체 손실 마진 10 dB
- 1 m 손실 40.2 dB (2.44 GHz 자유 공간)

| 단계 | LE 1M | LE Coded S=8 |
|---|---|---|
| 허용 최대 경로 손실 = 출력 − 감도 − 마진 | 0 − (−95) − 10 = **85 dB** | 0 − (−103) − 10 = **93 dB** |
| 자유 공간 (\(n=2\)) 거리 = \(10^{(L-40.2)/20}\) | 약 174 m | 약 437 m |
| 실내 (\(n=3\)) 거리 = \(10^{(L-40.2)/30}\) | 약 31 m | 약 58 m |
| 거리 비율 | 기준 | 자유 공간 2.5배, 실내 1.85배 |

감도 차이가 8 dB일 때 자유 공간에서는 \(10^{8/20} \approx 2.5\)배, 실내(\(n=3\))에서는 \(10^{8/30} \approx 1.85\)배만 늘어납니다. 규격의 최소 감도 요구(1M −70 dBm, S=8 −82 dBm)로 계산하면 차이는 12 dB이고, 같은 방식으로 자유 공간 약 4배(\(10^{12/20}\)), 실내 약 2.5배(\(10^{12/30}\))가 됩니다. "Bluetooth 5는 거리 4배"라는 홍보 문구는 자유 공간과 이상적인 감도 차를 가정한 값입니다.

대가는 airtime입니다. 251 B 페이로드(MIC 포함) 패킷은 1M에서 2120 µs이지만 Coded S=8에서는 17040 µs로 약 8배 길어져, 전류 소모와 채널 점유가 그만큼 늘어납니다([LE PHY](../le/phy.md)).

## RSSI { .l2 }

**RSSI(Received Signal Strength Indicator)**는 수신기가 측정한 신호 세기입니다.

| 출처 | 의미 | 값 |
|---|---|---|
| LE 광고 보고 (`HCI_LE_Advertising_Report`, `HCI_LE_Extended_Advertising_Report`) | 패킷 하나의 수신 세기 | dBm, −127…+20, 127이면 "측정 불가" |
| `HCI_Read_RSSI` (LE 연결) | 연결의 수신 세기 | 절대값 dBm |
| `HCI_Read_RSSI` (BR/EDR 연결) | **기준 수신 전력 범위(Golden Receive Power Range)와의 차이** | 상대값 dB. 0이면 범위 안 |

??? expert "전문가 노트 — RSSI로 거리 재기의 한계, 감도 규정"
    **RSSI 거리 추정.** \(d = 10^{(P_{1m} - RSSI)/(10n)}\)로 거리를 거꾸로 계산할 수 있지만, \(n\)이 환경마다 다르고 다중 경로 페이딩으로 RSSI가 순간적으로 10 dB 이상 흔들립니다. 10 dB 오차는 \(n=2\)에서 거리 3배 오차입니다. 근접 판정(가깝다/멀다) 정도에는 쓰이지만, 정밀한 거리는 [Channel Sounding](../le/channel-sounding.md)이 위상·왕복 시간으로 측정합니다.

    **광고의 TX Power 필드.** AD Type "Tx Power Level"이나 확장 광고 헤더의 TxPower를 함께 보내면 수신자가 경로 손실(= TxPower − RSSI)을 계산할 수 있습니다. 비콘 응용에서 흔히 쓰는 "1 m 기준 RSSI" 값은 규격이 아니라 응용 규칙입니다.

    **감도 정의.** 규격의 수신 감도는 정해진 오류율(LE는 비트 오류율 0.1 %에 해당하는 패킷 오류율 기준)에서의 입력 레벨입니다. 규격 요구치는 최소선일 뿐이고 상용 칩은 보통 20 dB 이상 좋은 값을 냅니다. 링크 버짓은 항상 실제 칩 데이터시트와 안테나 효율(작은 기기에서 −3 ~ −10 dBi도 흔함)로 계산해야 합니다.

    **RSSI 비교 주의.** RSSI의 절대 정확도는 칩과 보정 상태에 따라 수 dB씩 다릅니다. 서로 다른 기기의 RSSI를 직접 비교하기보다 같은 기기의 상대 변화를 보는 편이 안전합니다.

## Classic ↔ LE 비교

| 항목 | Classic (BR/EDR) | LE |
|---|---|---|
| 감도 선택지 | BR(GFSK)가 가장 강건, EDR은 더 높은 SNR 필요 | 2M < 1M < Coded S=2 < Coded S=8 순으로 강건 |
| RSSI 의미 (`HCI_Read_RSSI`) | 기준 범위와의 상대값 | 절대 dBm |
| 장거리 수단 | 출력 Class 1 | Coded PHY + 출력 Class 1/1.5 |
