!!! basic "Wi-Fi·셀룰러와 다른 점 미리 보기"
    Bluetooth는 같은 무선 통신이지만 설계 목표가 "빠르게"보다 **"싸고, 작고, 오래가게"**에 있습니다.

    1. **단순한 변조** — Wi-Fi·LTE가 OFDM과 고차 QAM을 쓰는 반면, 기본은 1 Msym/s **GFSK**입니다. 전력 증폭기와 수신기가 단순해 칩이 싸고 전류가 적습니다.
    2. **주파수 도약** — 넓은 채널 하나를 차지하는 Wi-Fi와 달리, 1–2 MHz 좁은 채널을 계속 바꿔 가며 간섭을 피합니다. 경쟁(CSMA) 대신 **약속된 시각에 약속된 채널**에서 만납니다.
    3. **기지국이 없음** — 셀룰러처럼 망이 시간을 나눠 주지 않습니다. 두 기기 중 한쪽(Central)이 타이밍을 주도하고, 나머지 시간은 둘 다 잠듭니다.
    4. **Host/Controller 분리** — 프로토콜 스택이 표준 인터페이스(HCI)로 둘로 나뉘어, 칩과 운영체제를 서로 다른 회사가 만들어도 맞물립니다.
