# 디지털 변조 (GFSK·DPSK)

!!! spec "규격 · 버전"
    Core v6.0 Vol 2 Part A (BR/EDR Radio: GFSK, π/4-DQPSK, 8DPSK) · Vol 6 Part A (LE Radio: 변조 특성, LE 1M·2M·Coded) · Vol 6 Part B (Coded PHY의 FEC와 패턴 매핑)
    1.0 GFSK 1 Mbps → 2.0 EDR π/4-DQPSK 2 Mbps·8DPSK 3 Mbps → 4.0 LE 1M → 5.0 LE 2M·Coded(S=2, S=8)·안정 변조 지수 → 6.0 CS 전용 LE 2M 2BT

!!! basic "한눈에 보기"
    Bluetooth의 기본 변조는 **GFSK(가우시안 주파수 편이 변조)**입니다. 비트 1이면 반송파 주파수를 조금 올리고, 0이면 조금 내립니다. 주파수만 바꾸고 진폭은 일정하므로

    1. **전력 증폭기를 단순하고 효율 좋게** 만들 수 있고 (진폭 왜곡을 걱정할 필요 없음)
    2. **수신기도 간단**합니다 (주파수 변화만 따라가면 됨)

    대신 한 심볼에 1비트밖에 못 실어 속도가 낮습니다. 속도를 원할 때 Classic은 위상 변조(**EDR**)를, LE는 심볼 속도 2배(**2M**)를 택했고, 거리를 원할 때 LE는 같은 비트를 여러 번 나눠 싣는 **Coded PHY**를 택했습니다.

## GFSK의 두 파라미터 { .l2 }

GFSK는 두 숫자로 성격이 정해집니다.

- **BT (대역폭-시간 곱)**: 비트 파형을 부드럽게 다듬는 가우시안 필터의 폭. 작을수록 스펙트럼이 좁아지지만 이웃 비트끼리 번짐(ISI)이 커집니다.
- **변조 지수 h**: 주파수 편이 폭을 심볼 속도로 나눈 값 \(h = 2\Delta f / R_s\). 클수록 1과 0이 잘 구분되지만 대역폭이 넓어집니다.

| PHY | 심볼 속도 | BT | 변조 지수 h | 비트율 |
|---|---|---|---|---|
| BR (Classic 기본) | 1 Msym/s | 0.5 | 0.28–0.35 | 1 Mbps |
| LE 1M | 1 Msym/s | 0.5 | 0.45–0.55 (안정 변조 지수: 0.495–0.505) | 1 Mbps |
| LE 2M | 2 Msym/s | 0.5 | 0.45–0.55 (안정 변조 지수: 0.495–0.505) | 2 Mbps |
| LE Coded | 1 Msym/s | 0.5 | 0.45–0.55 | 500 / 125 kbps |
| LE 2M 2BT (6.0, CS 전용) | 2 Msym/s | 2.0 | 규격 원문 확인 | Channel Sounding 전용 |

LE의 변조 지수가 BR보다 큰(0.5 근처) 이유는 수신 감도와 주파수 오프셋 허용 범위에 유리하기 때문입니다. 같은 1 Msym/s라도 LE 수신기가 더 단순하게 1/0을 판별할 수 있습니다. 대신 스펙트럼이 넓어져 LE는 2 MHz 채널 간격을 씁니다.

## EDR: π/4-DQPSK와 8DPSK { .l2 }

Core 2.0의 **EDR(Enhanced Data Rate)**은 심볼 속도는 1 Msym/s 그대로 두고, 한 심볼에 2비트 또는 3비트를 싣습니다. 정보를 **위상 변화량**(차동 위상)에 싣기 때문에 수신기가 절대 위상을 알 필요가 없습니다.

| 변조 | 심볼당 비트 | 위상 변화 | 비트율 | 패킷 예 |
|---|---|---|---|---|
| GFSK (BR) | 1 | — | 1 Mbps | DH5 (최대 723.2 kbps) |
| π/4-DQPSK | 2 | ±π/4, ±3π/4 | 2 Mbps | 2-DH5 (최대 1448.5 kbps) |
| 8DPSK | 3 | π/4 간격 8가지 | 3 Mbps | 3-DH5 (최대 2178.1 kbps) |

EDR 패킷은 **하나의 패킷 안에서 변조가 바뀝니다**. 액세스 코드와 헤더는 GFSK로 보내 기존 기기와 호환을 유지하고, 짧은 보호 구간(guard)과 동기 시퀀스 뒤 페이로드만 DPSK로 보냅니다. DPSK 구간은 진폭이 변하므로 송신기는 선형 증폭이 필요하고, 수신에는 GFSK보다 높은 SNR이 필요합니다. 그래서 A2DP 스트리밍 중 거리가 멀어지면 칩이 3-DH5 → 2-DH5 → DH5로 내려가며 버팁니다.

## LE 2M과 Coded PHY { .l2 }

| PHY | 방법 | 비트율 | 251 B+MIC airtime | 감도 요구 |
|---|---|---|---|---|
| LE 1M | GFSK 1 Msym/s | 1 Mbps | 2120 µs | −70 dBm |
| LE 2M | GFSK 2 Msym/s | 2 Mbps | 1064 µs | −70 dBm |
| LE Coded S=2 | 1M + FEC(부호율 1/2) | 500 kbps | 4542 µs | −75 dBm |
| LE Coded S=8 | 1M + FEC(1/2) + 패턴 매핑(×4) | 125 kbps | 17040 µs | −82 dBm |

**Coded PHY**는 변조는 LE 1M과 같고, 그 앞에 두 단계를 추가합니다.

1. **FEC 부호화**: 길쌈 부호(convolutional code, 부호율 1/2)로 비트를 2배로 늘려 오류 정정 능력을 얻습니다.
2. **패턴 매핑**: S=8이면 부호화된 비트 하나를 4개의 칩 패턴으로 바꿔(총 8배 확산) 더 약한 신호에서도 판별할 수 있게 합니다. S=2이면 패턴 매핑은 그대로 통과합니다.

Coded 패킷은 앞부분(액세스 주소, 부호화 지시자 CI)을 항상 S=8로 보내고, CI가 알려 준 대로 나머지(PDU, CRC)를 S=2 또는 S=8로 보냅니다. 자세한 패킷 구조는 [LE PHY](../le/phy.md)와 [패킷 구조](../le/packet.md)에서 다룹니다.

??? expert "전문가 노트 — 변조 지수, 주파수 드리프트, 2M의 비용"
    **안정 변조 지수(Stable Modulation Index).** 5.0에서 추가된 선택 기능으로, 송신기가 h를 0.495–0.505로 좁게 유지한다고 알리면 수신기가 더 정교한 복조(코히런트에 가까운 검출)를 써서 감도를 높일 수 있습니다. 지원 여부는 LE 기능 비트로 교환합니다.

    **주파수 오프셋과 드리프트.** 규격은 반송파 주파수 오차와 패킷 안에서의 드리프트 한도를 정합니다. 싼 수정 발진기(±50 ppm이면 2.44 GHz에서 ±122 kHz)를 쓰면 오프셋이 편이 폭의 상당 부분이 되므로, 수신기는 프리앰블에서 오프셋을 추정해 보정합니다. 2M PHY의 프리앰블이 2바이트(1M은 1바이트)인 것도 같은 시간(8 µs)을 확보하기 위해서입니다.

    **2M의 비용.** 2M은 airtime을 절반으로 줄여 전류와 충돌 확률을 낮추지만, 대역폭이 넓어 인접 채널 간섭에 약하고 감도 요구치는 1M과 같아도 실제 칩에서는 수 dB 나쁜 경우가 많습니다. 링크가 약하면 [LE 전력 제어](../le/power-control.md)나 PHY 갱신(`LL_PHY_REQ`)으로 1M·Coded로 내려가는 전략이 필요합니다.

    **EDR의 성형 필터.** EDR DPSK 구간은 루트 레이즈드 코사인 필터(roll-off 0.4)로 성형합니다. 같은 1 MHz 채널에 맞추기 위함이지만 진폭 변화(PAPR)가 생겨 PA를 선형 영역에서 써야 하므로, EDR 송신 출력은 BR보다 약간 낮게 설정되는 경우가 많습니다.

## Classic ↔ LE 비교

| 항목 | Classic (BR/EDR) | LE |
|---|---|---|
| 기본 변조 | GFSK h 0.28–0.35 | GFSK h 0.45–0.55 |
| 속도 향상 수단 | 위상 변조 (EDR 2/3 Mbps) | 심볼 속도 2배 (2M) |
| 거리 향상 수단 | 없음 (출력·DM 패킷 FEC 정도) | Coded PHY (FEC + 패턴 매핑) |
| 채널 간격 | 1 MHz | 2 MHz |
