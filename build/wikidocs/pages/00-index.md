**Bluetooth Classic(BR/EDR)부터 Low Energy, LE Audio, Mesh, 그리고 Core 6.x Channel Sounding까지.**

처음 공부하는 사람은 개념부터, 현업 엔지니어는 규격 디테일까지 한 페이지 안에서 단계적으로 읽을 수 있도록 만든 한글 블루투스 핸드북입니다.

## 이 책을 읽는 법

모든 페이지는 같은 틀을 따르고, 난이도를 색 표시로 구분합니다.

| 표시 | 대상 | 내용 |
|---|---|---|
| 🟢 기초 | 처음 공부하는 사람, 비전공자 | 개념, 비유, "왜 이렇게 만들었나" — 수식 없이 |
| 🔵 중급 | 전공자, 신입 엔지니어, 앱 개발자 | 구조, 파라미터 표, 그림, 동작 순서 |
| 🔴 전문가 | 펌웨어·드라이버·RF 엔지니어 | 규격 수식, 예외 처리, 버전별 변화, 실무 팁 |

[[TIP("📘 스펙 박스")]]
각 페이지 맨 위의 이 상자에는 관련 Bluetooth Core Specification의 Vol/Part와 기능이 들어온 Core 버전, 해당하면 프로파일·서비스 규격 이름이 적혀 있습니다. 본문을 읽다가 원문을 확인하고 싶을 때 바로 찾아갈 수 있습니다.
[[/TIP]]

본문에서 **굵게 표시된 페이지 이름**은 이 책의 다른 페이지를 가리킵니다. 왼쪽 목차에서 같은 이름의 페이지를 찾으면 됩니다.
