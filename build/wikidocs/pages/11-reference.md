본문을 읽다가 "그 값이 뭐였더라", "그 기능은 몇 버전이었지"를 빠르게 찾기 위한 섹션입니다. 개념 설명보다 표와 링크 중심으로 구성했고, 각 항목은 자세히 다루는 본문 페이지로 연결됩니다.

| 페이지 | 핵심 질문 |
|---|---|
| **Classic vs LE 비교** | 같은 Bluetooth인데 PHY·채널·연결·전력·오디오·보안이 어떻게 다른가? |
| **Bluetooth vs Wi-Fi vs 5G** | 세 무선 기술은 대역·거리·속도·전력·용도에서 어떻게 나뉘나? |
| **Core 버전별 기능 인덱스** | 이 기능은 Core 몇 버전에서 들어왔고, 이 책 어디에 설명되어 있나? |
| **규격 인덱스** | Core 규격의 Vol/Part 구성과 주요 프로파일·서비스 규격은? |
| **약어 사전** | LL, ATT, CIS, PAwR… 약어의 풀네임과 뜻은? |
| **계산기** | airtime, 처리량, 평균 전류를 직접 넣어 계산하려면? |
| **참고 자료** | 공식 규격, Assigned Numbers, 도구, 오픈소스 스택은 어디서 구하나? |

[[TIP("💡 수치 검산")]]
이 책의 airtime·처리량·채널 주파수 수치는 모두 저장소의 `tools/bt_numbers.py` 한 곳에서 계산합니다. 원고를 고친 뒤에는 다음 명령으로 본문에 적힌 대표 값이 계산 결과와 일치하는지 확인할 수 있습니다.

```bash
python3 tools/bt_numbers.py          # 채널 주파수, airtime, 처리량 표 출력
python3 tools/bt_numbers.py --check  # 본문 대표 값 검산 (불일치 시 종료 코드 1)
```

예: 1M PHY 251 B + MIC = 2120 µs, 2M = 1064 µs, Coded S8 최대 17040 µs, 1M 응용 처리량 상한 약 791 kbps, 2M 약 1402 kbps, 3-DH5 비대칭 2178.1 kbps.
